# RHL — Challenges: "Highlight Reel" (Brainstorm v0.1)

Short, scripted scenarios (1–5 minutes each) presented as **Meridian "Highlight Reel" segments**.
Each has **Bronze / Silver / Gold** objectives and unlocks cosmetics. Many are built for **couch co-op** and **goalies**.

---

## 1. Format

- **Packs** of 6–8 challenges, unlocked in order (earn medals to open the next pack).
- **Medals:** Bronze = complete it · Silver = harder condition · Gold = brutal condition.
- **Intro:** Dale & Knuckles set the scene ("Down two with a minute left and Kowalski's out for blood…").
- **Instant retry** (one button), best times/scores saved.
- **Solo, Co-op, or Goalie** tags on every challenge.
- Difficulty: challenges use fixed AI settings so medals mean something (User sliders still allowed; using easier sliders shows a small icon on the medal).

### Rewards
Gear, sticks, tape colors, **goalie mask designs**, pad designs, celebrations, taunts, goal horns, logo-editor pieces, arena weather variants, jersey styles, and **Legends** unlocks (classic versions of star players).

## 3. Network Specials (offline rotating challenges)
- A **daily/weekly generated challenge** made from random combinations (arena + weather + scenario + items + objective).
- Fully offline (seeded by the date). Keeps the mode fresh after all packs are done.

---

## 4. Challenge Editor (later, optional)
- Build your own challenges with the same settings (teams, score, clock, injuries, items, objectives) and share as files.
- Owner can make challenges for the son (or vice versa).

---

## 5. Tech: Challenge Definition (Data Asset)
| Field | Example |
|---|---|
| Setup | Teams, arena, weather/time, players per side, controlled player(s), goalie human/AI |
| Start state | Score, clock, period, injuries, penalties, Hype tier, items held |
| Spawn Director | Scripted drop list or override config |
| Hazards / events | Forced Network Event at a set time |
| Objectives | Bronze/Silver/Gold conditions (event counters + timers) |
| Fail conditions | Time out, goals allowed, death, etc. |
| Rewards | Unlock IDs |
| Tags | Solo / Co-op / Goalie / Versus |
| Intro VO | Announcer line set |

All challenges are data — new ones need no code. Objectives use the same game events as announcers and stats.

## 6. Build Order
