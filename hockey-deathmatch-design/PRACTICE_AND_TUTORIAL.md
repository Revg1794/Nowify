# RHL — Practice Mode & Tutorial (Brainstorm v0.1)

Both live in **The Pit** — the abandoned community rink. Lore twist: **it's the one place in the RHL with no Meridian cameras**,
so the mentors talk straight. No broadcast package here — just flickering lights, graffiti, and honest advice.

---

## 1. Principles
1. **Optional, never forced.** First launch offers the tutorial; skip anytime.
2. **Short lessons** (1–3 min each), learn by doing, one idea at a time.
3. **Respect experienced players.** A **Fast Track** for NHL-games veterans teaches only what's different in RHL.
4. **Goalie gets a full track** — not an afterthought.
5. **Practice is a real tool**, not just a tutorial leftover: sandbox, drills, shooting machine, sparring partner.

## 4. Practice Mode (Sandbox)

### Setup
- Arena: **The Pit** by default, or **any arena** (with its hazards) once unlocked.
- Play as skater or goalie; any team/player (including custom & stars).
- Couch: up to 4 players practicing together.

### Sandbox Menu (pause → Practice Tools)
| Tool | What it does |
|---|---|
| **Spawn Players** | AI teammates/opponents, **training dummies** (stand, skate a path, or charge you) |
| **Spawn Items** | Any item, anywhere (incl. arena exclusives) |
| **Trigger Events** | Zamboni, Mascot Invasion, Power Flicker, Glass Shatter, any Network Event |
| **Hazards** | On/off, trigger now |
| **Reset** | Puck to me · Players to positions · Full reset |
| **Rewind 5 s** | Uses the replay recorder — rewind and retry a moment |
| **Slow-mo** | 0.25× / 0.5× / 1× |
| **Invincible** | Toggle for you / everyone |
| **Overlays** | Input display, **shot speed**, **hit damage numbers**, Hype gain popups, Perfect Save window visualizer, AI debug (optional) |

### Drills (presets + save your own)
| Drill | Description |
|---|---|
| **Shooting Gallery** (goalie) | Shot machine: choose shot types, speeds, locations, frequency, screens, deflections, crease crashers |
| **Breakaway** | Repeated 1-on-goalie runs (shooter or goalie side) |
| **2-on-1 / 3-on-2** | Odd-man rushes |
| **Power Play / Penalty Kill** | Special teams setups |
| **Sparring Partner** | Fight drill: AI fighter with adjustable **Fight Skill**; optional slow-mo telegraph aid |
| **Hit Course** | Dummies along the boards — build speed, chain crushes |
| **Hazard Run** | Survive an arena's hazards for 60 s |
| **Shootout Practice** | Shootout of Death rounds vs AI with item roulette |

- **Save Drill:** store any setup (players, items, events, settings) as a named preset.
- Drills can be exported/shared (same format as Challenges — the Challenge Editor can import them).

### Stats Panel
Shots (speed, accuracy), saves (reaction time, Perfect Save %), hits (tier breakdown), fight stats (blocks, parries) — per session.

## 6. Tech Notes
- Lessons = **data assets** (steps, objectives, host lines, setup) built on the **Challenge framework** (same objectives/events system).
- Host lines via TTS (Frankie, Tommy, Knuckles) — off-air audio (dry room sound, no broadcast processing).
- Sandbox tools reuse Spawn Director / Event Director debug commands with a UI.
- Rewind uses the replay recorder (restore state from the last 5 s).
